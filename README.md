# Smart Lender

## Loan Approval Prediction using Machine Learning

A Flask-based machine learning web application that predicts whether a loan application is likely to be **Approved** or **Rejected** based on applicant information such as income, credit history, education, employment status, and loan amount.

---

## Features

- Loan approval prediction using Machine Learning
- User-friendly Flask web interface
- Applicant details input form
- Real-time prediction results
- Trained ML models saved using Pickle
- Clean and responsive UI

---

## Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML5
- CSS3

---

## Machine Learning Models

- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Gradient Boosting
