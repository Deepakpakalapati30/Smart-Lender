# Smart Lender

## Loan Approval Prediction using Machine Learning

### Project Overview
Smart Lender is a machine learning web application that predicts whether a loan application is likely to be approved based on applicant details.

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML
- CSS

### Machine Learning Models
- Decision Tree
- Random Forest
- KNN
- Gradient Boosting (XGBoost)

### Features
- Data preprocessing
- Data visualization
- Model training and evaluation
- Loan approval prediction
- Flask web application
